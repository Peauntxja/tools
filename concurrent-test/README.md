# API 并发安全测试框架

一个用于测试 API 接口的并发性、幂等性和安全性的 Python 测试框架。

## 功能特性

- **并发测试**：支持高并发请求测试，统计 QPS、响应时间、成功率等指标
- **幂等性测试**：验证接口在多次相同请求下的响应一致性
- **基础安全性测试**：
  - IP 限制测试（支持代理池和请求头修改）
  - Token 验证测试
  - 并发安全测试
- **高级安全性测试**：
  - **协议与链路安全**：HTTPS 支持测试、重放攻击防护测试
  - **缓存控制**：检查响应头中的缓存控制指令，防止敏感信息被缓存
  - **CORS 与 Referrer 策略**：测试跨域访问控制和 Referrer 验证
  - **健壮性与模糊测试**：超长 Token、特殊字符注入、异常数据处理测试
  - **生命周期与状态同步**：Token 失效机制、多端登录冲突、状态同步测试

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
python main.py
```

## 配置说明

编辑 `config/settings.py` 配置接口 URL、token、测试参数等。

## 测试报告

测试完成后会在 `reports/` 目录下生成以下格式的测试报告：

- **Markdown 格式**：规范的测试文档，包含完整的测试用例、结果分析和改进建议
- **HTML 格式**：可视化的测试报告，包含图表和详细数据
- **JSON 格式**：原始测试数据，便于程序化处理

Markdown 报告是标准的测试文档格式，适合作为正式的测试报告提交。
